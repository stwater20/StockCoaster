# 🎢 股市雲霄飛車 StockCoaster（台股版）

把台股日線變成像素風的橫向卷軸雲霄飛車：漲是爬坡、跌是俯衝，紅漲綠跌。介面是 Apple 玻璃風格，支援亮色／暗色主題。

線上玩：**https://stockcoaster.sectools.tw/** ，個股直達：`/2330/`、`/0050/?range=5y`、`/2454/?start=2020-01-01&end=2024-12-31`

## 本機啟動

```bash
python3 server.py
```

打開 http://localhost:8765 。只需要 Python 3 內建模組，不用安裝任何套件。
（server 會代理 Yahoo Finance 的台股資料，因為瀏覽器直接抓會被 CORS 擋。直接開 `public/index.html` 也能玩，但會用模擬資料。）

## 玩法

- **選股**：預設台積電 2330、0050，也能輸入任何上市（.TW）／上櫃（.TWO）代號
- **期間**：3 個月、半年、今年、1／2／5／10 年，或自訂起訖日期（超過 3 年改用週線）
- **模式**：🎢 自動觀賞（預設）／🎮 遊戲模式（點畫面或空白鍵跳躍、二段跳，吃金幣紅包、跳過利空炸彈，三顆愛心）
- **發車前猜猜看**：猜終點比起點高還是低
- **畫面**：側面 K 線視角，像素風的列車沿著股價軌道跑，上方小地圖顯示整段走勢與目前位置
- **主題**：右上角切換亮色（白天、雲朵）／暗色（夜空、星星），會記住你的選擇
- **速度**：0.5×～4×（鍵盤 `1`–`4`）；`P`／`Esc` 暫停（自動模式也可用空白鍵）

## 小巧思

- 🔮 **AI 預言家**：均線、RSI、動能 + 600 條蒙地卡羅路徑，鋪出「今天之後」30 個交易日的紫色未來軌道（沒有支架、飄在空中），外加 80% 機率布幕
- 🏙️ **成交量城市**：軌道下方每棟大樓的高度 = 當日成交量
- 🪙 創新高噴金幣＋放煙火、🌧️ 從高點回檔超過 15% 開始下雨、天空隨近期漲跌變色
- 😱 尖叫指數、G 力、時速；乘客頭上會冒對話泡泡（`!`、`$`、`?`），大跌時畫面震動、高速有速度線
- 🔊 全合成音效：風聲、爬坡喀喀聲、尖叫、煙火
- 🏆 25 個成就（存在瀏覽器 localStorage），含兩個隱藏彩蛋

> 資料來源 Yahoo Finance，可能有延遲。AI 預測是統計玩具，純屬娛樂，不構成投資建議。

## 部署（GitHub Pages）

推到 `main` 會由 `.github/workflows/pages.yml` 執行 `build.py`：每檔上市櫃股票與 ETF 各產生一頁（`/<代號>/`，含獨立標題、描述、canonical、結構化資料），外加 `sitemap.xml`、`robots.txt`、`404.html`。
Pages 上沒有 Python 代理，前端會改用 FinMind 公開 API（支援 CORS），並自動還原股票分割。
